## Stability contract (architecture §7.2)

- **1.0.0** → initial V1 table.
- **1.0.1** → added `execution_provider` field on `ActionSpec` (default
  `"backend"`; `hisec.restore_edr` declared `"server_inline"`); added
  `BACKEND_NOT_IMPLEMENTED` to keep macOS `type_text`/`select`/`get_text`
  reporting False. `status.action_space` output unchanged.

Adding a backward-compatible action → minor bump.
Removing an action or changing its accepted semantics → major bump.
Changing accepted enum values → major bump.

## Layer boundary (PR review — Issue 2 / Blocker 2)

P0.1 owns: "which actions exist and which backends statically support them".
P0.1 does NOT probe live backend instances. The `hasattr` runtime probe
lives in `runtime_capability.py` (P1.1 territory).

## Public API

```python
from action_catalog import (
    CATALOG_VERSION,            # "1.0.1"
    ACTIONS_V1,                 # tuple[ActionSpec, ...]
    ActionSpec,                 # dataclass
    ActionEntry,                # dataclass
    CatalogConstructionError,   # exception
    VALID_CATEGORY, ... ,       # enum sets
    BACKEND_NOT_IMPLEMENTED,    # per-backend gaps
    build_registry,             # validation entry
    get_spec, get_spec_by_tool, get_spec_by_code,
    is_statically_supported,
    specs_for_backend,
    live_enablement_for,        # static-only lookup
    canonical_catalog_bytes,    # raw deterministic JSON bytes
    catalog_digest,             # "sha256:<hex>"
    status_action_space,        # legacy Boolean map (byte-compat)
    get_action_catalog,         # JSON-friendly catalog payload
    get_action_capability,      # bool convenience
    backend_capability_view,    # immutable MappingProxyType
    # P1.1 territory (importable, not called by P0.1):
    runtime_capability_for,
    runtime_capability_view,
)
```
