# 回放入口窗口受控恢复：第一阶段设计 R0

状态：待审查；尚未实现或实机验收。本阶段仅处理 HiSec 已存在入口窗口的受控激活与重新获取，不声称重建录制时的窗口因果链。

## 现状与证据边界

- 当前 legacy 入口依次执行 connect、strict lock、verify；这发生在 trace store 打开及可能的 product-run 租约申请之前（`agent/recording/runtime.py`）。无 rootAutomationId 会选择 legacy 锁路径；**不意味着不会申请租约**：锁成功后仍会根据目标能力调用 `_begin_product_run_if_available`。锁失败则不会走到租约申请。
- Windows 多条件连接返回 `connect_target_not_found` 或 `connect_target_ambiguous`；其他错误不等价于目标缺失。`activate_edr` 可能启动客户端和 Windows 服务，不能作为“只激活已有窗口”的实现。
- 附件转述了一次较晚的窗口枚举：EDRClient 和 logo1 当前无窗口。此处未独立取得原始响应、时间戳和对应历史 connect 请求，不能据此认定先前失败时的根因；原始证据待补。
- GoldenTrace 当前不含 `recording.windows`，其严格字段解析也不接受随意增加的顶层字段；通用窗口因果链不在本阶段内。

## 目标、权限与边界

回放可显式启用“仅激活已有入口窗口”。默认关闭；旧 golden 和旧调用保持既有行为。启动客户端是独立授权能力，本阶段不实现；启动、停止或修改服务、策略及用户数据均不在本阶段范围。窗口确实不存在时，本阶段报告 `entry_window_absent`，不启动程序，也不声称已重建。若目标工具无法证明仅激活已有窗口，拒绝执行，不调用现有 `activate_edr` 代替。

只针对目标本机已注册产品能力、实际后端和入口 `ReplayScope` 的精确身份匹配，禁止仅凭 golden 中 profile/application 自报信息授权执行。无产品租约或目标能力不完整时，不自动恢复。租约是 GUI 协作并发栅栏，不是远程身份认证，也不证明 RDP 上无人操作；继续遵守用户会话和外部控制者的检查要求。

## 协议与顺序（拟建设，非现有 API）

1. 完成本地 golden、profile、资源及目标能力预检；建立持久的运行记录。不能持久记录时，在任何目标副作用之前失败。
2. 申请目标端产品独占租约。目标不支持、租约冲突、过期或令牌校验失败时拒绝恢复。记录租约 ID 与时效，禁止记录 token。
3. 通过持有租约的受控接口枚举并解析原始入口身份。仅结构化 `connect_target_not_found` 允许进入恢复评估；歧义、权限、通信、后端和格式错误直接失败。对无法区分未找到与枚举失败的后端，禁止自动恢复。
4. 若有且仅有一个满足原始完整身份、但需要激活的窗口，使用目标端新增的租约授权能力将其激活；能力必须禁止进程启动、服务操作和控件点击。若窗口不存在、匹配多个或身份不可证明则拒绝。注意：若 connect 的 not_found 本身意味着无匹配窗口，必须重新只读确认，并说明何种可验证的连接状态允许这一步；不得把矛盾结果硬判为可恢复。
5. 使用原始进程、标题及 rootAutomationId 等全部适用身份重新获取；严格锁定并验证实际属主和前台状态。恢复的目标与入口不同、身份缺失或任一步失败均拒绝执行测试步骤，不放宽匹配。root 与 legacy 两条路径各自明确实现和能力门槛，不得丢弃 root 身份。
6. 所有退出路径释放本次租约及本次取得的锁；资源归属、租约过期、连接丢失及释放失败必须记录。不能清除或解锁其他运行者拥有的状态。租约持有后，现有 legacy 无 token 调用可能被产品策略拒绝；实现前须新增或复用明确的 token 授权路径，不能只调整调用顺序，也不能绕过策略。

## 审计与失败语义

恢复前写入关联 run ID 的意图记录，包含原始入口身份、门控与缺失原因、租约信息（不含 token）、操作种类及时间；追加每次尝试、目标端回执、重连/锁定/验证、失败阶段和清理结果。记录与最终回放报告关联；即使 runtime 尚未构造或进程意外退出，也可保留“已计划/结果未知”的记录。持久写失败时停止后续副作用；不得把激活成功当作测试通过。

对超时或失联，结果为未知而不是未执行；不自动重复副作用。原始响应应脱敏保存并关联摘要或哈希；日志不得包含令牌、凭据或不必要的用户数据。租约释放失败单独报告，不能覆盖原始失败。

## 验收门槛

- 原行为：默认关闭、旧 golden、非 HiSec、未提供能力均不发生恢复动作。
- 触发与身份：明确 not_found、已有唯一入口可激活的可复现场景；真正缺失、多个候选、进程/标题/root 不一致、无效响应、权限错误、目标失联均不误操作。
- 并发：其他 product-run 持租约、租约申请失败/过期、并发录制或外部用户活动时不激活；测试 token 限权及 legacy 调用的策略兼容。
- 权限与副作用：服务停止或未知、客户端不存在时不运行 `sc start`、不启动客户端、不点击窗口；验证不会关闭或重置已有用户状态。
- 异常与审计：审计写失败、激活超时/异常、重连/锁定/验证失败、释放失败与进程中断均有准确结果和可追溯记录；不在失败后执行录制步骤。
- 实机：在确认目标、用户会话和控制者安全后，用真实窗口及受控入口完成恢复、严格身份校验和原始录制回放；记录请求、响应、时间和截图/哈希。离线通过不等于实机通过。
